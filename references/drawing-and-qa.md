# 纯黑白制图规范与文档成品验收参考

阶段二制图与编译文档前必读。通过**固定画布预设、简体宋体锁死、二维/三维分流、六大制图公理与真实渲染终检**，确保每次生成的题图、公式与打印版式高度稳定一致。

## 一、图形路由：先判有效维度，再选工具

- **必要配图原则：** 除纯概念辨析且图示无信息增益外，凡含具体物理装置、运动边界、空间方位、图像或实验操作的题目，学生版必须配信息图，严禁以“文字已写清”免图，也不放纯装饰图。
- **二维共面图 / 定量图（主路由：`scripts/physics_draw.py`）：** 函数图像、受力/运动简图、纸带、电路、光路、实验仪器刻度等，一律复用 `scripts/physics_draw.py` 精确渲染 300 DPI 纯黑白图。
- **三维空间场景（立体主图路由）：** 题目依赖前后深度、空间夹角、三维落点或立体复合场时，**必须提供三维立体主图**（俯视、侧视、正视图只能作为辅助视图，不得替代立体主图）。优先用内置生图工具生成干净简洁的纯黑白/浅灰三维结构底图，通过几何关系核验后再用矢量层叠加点名、物理量、箭头与尺寸线（**图层解耦**：改字不重画已合格的三维结构）。二维共面题不为“好看”强加透视。
- **单图串行：** 一次只生成或修改一张独立图，渲染保存并目视验收通过后，再处理下一张。

### 统一线宽与字号常量（本技能教学印刷参数，对应 `scripts/physics_draw.py`）
- **三级线宽（原图 $\times 0.72$ 纸面值）：** `LW_THICK = 1.80 pt`（外轮廓/轨道/地面/主曲线）、`LW_MED = 1.35 pt`（坐标轴/物理矢量，须与轮廓或中心点画线偏移分离）、`LW_THIN = 0.90 pt`（投影虚线/尺寸线/细绳/弹簧/剖面线/浮置加速度）。
- **放大字号（原图 $\times 0.72$ 纸面值）：** `FS_SYM = 20.0 pt`（`14.4 pt`）、`FS_AX / FS_CAP = 18.5 pt`（`13.3 pt`）、`FS_TIK / FS_CN = 17.0 pt`（`12.2 pt`）、`FS_SUB = 13.0 pt`（`9.4 pt`）。辅助标注最低不得小于 `FS_TIK - 1.5`（`15.5 pt`，纸面仍 `> 11 pt`）。

## 三、标准简体常规宋体锁死与符号约定

1. **规避 `.ttc` 日文 0 号字形与粗体错配：** Linux 系统 `NotoSerifCJK-Regular.ttc` 索引 0 为日文 JP、索引 2 才是中国大陆简体常规宋体（`SC Regular`）。直接传 `.ttc` 给 Matplotlib 会导致“门、运、通”等字变形。统一调用 `physics_draw.get_cn_font()`，自动提取缓存 `NotoSerifCJKsc-Regular.otf`，拒绝粗体与未拆包日文 TTC。
2. **克制中文脚标：** 优先使用标准变量字母、数字与简短拉丁说明下标（$v_0, v_{\mathrm{m}}, t_1, t_2$），在正文或图例交代语义；确需中文下标时统一调用 `draw_cn_sub()`，严禁在 Matplotlib `mathtext` 中使用 `\text{...}` 或 `\triangle`。
3. **标准引用严谨口径：** 本规范参考 GB/T 3102、GB/T 4457.4、GB/T 4728 的相关教学制图原则并结合 A4 打印缩排设定参数；不笼统宣称单张教学示意图全面符合全部国家标准条款。

## 四、通用制图六大公理（逐图目视必检）

1. **纯黑白零彩色与去拟物化：** 线条、曲线、箭头、质点与文字一律纯黑（`#000000`）；多曲线仅靠实线/虚线/点画线区分；刚性构件仅用极浅中性灰（`#EFEFEF`）或无底框 $45^\circ$ 细剖面线；小球画纯黑实心点或空心圆，禁止水滴、高光、阴影等拟物装饰。
2. **接触闭合不穿模：** 物块、小球轮廓严格贴合支撑面（斜面物块用 `draw_block_on_slope(..., slope_dir='down_right'|'up_right')`，核对倾斜方向防错位），相切轨道平滑无折角。
3. **标注外置零碰撞：** 文字与所有图线、箭头、节点及场符号保持清晰净空（纸面 $\ge 1.5\ \mathrm{mm}$），严禁线条穿字；密集区用外置细箭头引出或加纯白底遮罩断线；大字号须同步放宽 `xlim/ylim` 与子图间距 `w_pad >= 0.85`。
4. **同类量尺度保真（$\pm 20\%$）：** 同一视图中题干给出数值的同类长度、高度、半径、间距，图面视觉比例与数值比相对偏差控制在 $\pm 20\%$ 内，禁止大小倒挂；如用断轴须明确标识。
5. **箭头与线型语义分离：** 物理矢量用中粗单向实心箭头；尺寸线用细双向尖端朝外箭头配垂直短界线（严禁内翻成叉号）；投影参考线无箭头；三维交叉不相交线段断开后方线。
6. **学生初态图与教师演化图严格隔离：** `figs/fig_qXX.png` 仅呈初始构型与题干已知条件，**严禁画出待求轨迹、未知落点、临界位置或解答辅助线**；`figs_sol/sol_qXX.png` 可叠加隔离受力、矢量分解直角、$v\text{-}t$ 面积阴影与临界走廊。

## 五、公式、表格、分页与真实渲染终检规范

1. **Markdown 与原生 OMML 避坑：**
   - 所有公式使用 `$...$` / `$$...$$`，由 Pandoc 转为原生 Word OMML；代数商优先用 `\frac{...}{...}` 上下分式，数值与单位间留 `\ ` 间距且单位正体；
   - **填空等号移出公式外：** 写 `$x_2$ = __________` 而非 `$x_2 =$`，防 LibreOffice 渲染为 `¿`；
   - **列表前必空行、选项零缩进：** 防列表粘连与误判代码块；
   - **量纲与正方向一致：** 相加各项量纲相同，无量纲比值分子分母物理含义对应；极值表述（最高/最低、最大位移/最大位移大小）与正方向约定一致。
2. **Pandoc 基底模板与分页控制（已封装入 `scripts/build_docx.py`）：**
   - `build_reference_docx()` 自动拉取 `pandoc --print-default-data-file reference.docx` 为基底并覆写 A4 纸张（`21.0 × 29.7 cm`）与宋体/黑体样式，完整保留 `Table`/`Compact` 内建样式，彻底根除 LibreOffice 表格坍塌；
   - `postprocess_docx()` 自动写入表格全框线与浅灰表头、居中卷头与嵌图，并自动为标题及公式/图片前的冒号引导句设置 `keep_with_next`，减少页末孤行；
   - Markdown 中的 `\newpage` 在 DOCX 中未必生效，确需强制分页应使用 Word 原生段落属性并目视验证 PDF 实际分页。
3. **七重自动门禁 + 真实 PDF 目视验收：**
   - 运行 `python scripts/build_docx.py compile ... --pdf --preview-dir ...`，必须通过全部 7 项代码断言（`raw_$=0`、无代码块误判、`trailing_eq=0`、含表格必有 `Table` 样式、A4 尺寸锁死、图数与宽高比误差 `< 0.5%`、全图 `print_scale ∈ [0.62, 0.92]`）；
   - **真实渲染抽检铁律：** 必须打开 `preview_dir` 中的关键 PDF 渲染页（表格页、填空页、双子图页、公式密集页、末页）目视核验；**OMML 数量正确或源码无误不能证明实际渲染无误**；用户重复指出同一缺陷时重新开项并对比前后渲染截图；交付说明中如实写明已验证的渲染器（如 LibreOffice PDF），不夸大宣称未测环境。
